About Civic Connects

Mission & Platform Architecture

Civic Connects is an enterprise-grade municipal grievance reporting and tracking web platform designed to bridge citizens and local municipal authorities. Citizens can pinpoint infrastructure hazards (potholes, water leaks, electrical hazards, uncollected solid waste), attach verifiable photographic proof with geolocation coordinates, and monitor the live resolution lifecycle.

Technical Implementation

  • Backend: Python 3 with Flask web framework, modular blueprints (auth, citizen, admin, complaints).
  • Database Engine: MySQL / MariaDB (InnoDB, UTF-8 collation) with connection pooling and localized fallback engine for zero-dependency reliability.
  • Security: Password hashing via werkzeug.security (scrypt algorithm), session management with HTTP-only cookies, role-based access decorators.
  • File Storage: Strict MIME-type checking, UUID prefix collision protection in static/uploads/complaints/.
  • Frontend: Vanilla HTML5, CSS3 Custom Properties (variables), and Vanilla JavaScript without bloated heavy frameworks.

Relational Database Schema (DDL)

The relational model utilizes 4 primary tables with foreign key constraints, cascading deletes, and optimized b-tree indices:

  • users: Manages credentials, roles ('citizen', 'admin'), and contact addresses.
  • departments: Municipal boards (Roads, Water, Electricity, Sanitation, Drainage, Streetlights).
  • complaints: Grievance tickets with unique ticket_number (e.g. #CC-8421), GPS coordinates, status ENUM, and remarks.
  • complaint_logs: Immutable audit history tracking timestamped status changes and authority notes.

Access & Portals

Municipal Authority (Admin): Contact system administrator for credentials.
Resident Citizens: Register a verified resident account directly via the Create Account portal.
